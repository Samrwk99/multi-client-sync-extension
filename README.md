### Multi Client Sync Extension
# You need both the plugin and extension for this to work
This project contains both a Sillytavern [Plugin](https://github.com/Samrwk99/multi-client-sync-plugin) and [Extension](https://github.com/Samrwk99/multi-client-sync-extension) that sync up multiple tabs open connected to the same Sillytavern instance.
It supports chat streaming, avoids having the same chat overwritten by another tab's usage and has the option to stop generations in another tab.

## Install and set up the Extension:
You can install it manually or through the Sillytavern UI.

# Install through the SillyTavern UI

1. Open up SillyTavern.
2. Open the Extensions panel.
3. Select Install Extension.
4. Paste the following GitHub repository URL: ```https://github.com/Samrwk99/multi-client-sync-extension```
5. Click install and restart SillyTavern.

# Install manually

1. Navigate to your SillyTavern directory.
2. Navigate to `/public/scripts/extensions/third-party/`
3. From this directory, run:

```bash
git clone https://github.com/Samrwk99/multi-client-sync-extension
```

4. Restart SillyTavern.
   
# Get the plugin
You can get the plugin and view the installation instructions here: [Multi Client Sync Plugin](https://github.com/Samrwk99/multi-client-sync-plugin)
